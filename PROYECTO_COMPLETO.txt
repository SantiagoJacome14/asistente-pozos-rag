❓ PREGUNTAS FRECUENTES:

P: ¿Necesito Python instalado?
R: Sí, Python 3.8+ en: python.org/downloads

P: ¿Mi documento se envía a OpenAI?
R: Solo el texto se procesa, no se guarda. Los embeddings 
   se generan con OpenAI pero se guardan localmente.

P: ¿Puedo usar sin conexión a internet?
R: No, necesitas OpenAI API. Puedes usar Ollama para local.

P: ¿Se guardan mis preguntas?
R: Solo en la sesión actual. Cierra la app = datos borrados.

P: ¿Puedo cambiar el modelo a GPT-4?
R: Sí, edita en config.py: OPENAI_MODEL_CHAT = "gpt-4"

🐛 SI ALGO NO FUNCIONA:

1. Verifica que (venv) está activado
   └─ En Windows: .\venv\Scripts\activate
   └─ En Mac/Linux: source venv/bin/activate

2. Reinstala dependencias
   └─ pip install -r requirements.txt --force-reinstall

3. Valida tu API Key
   └─ Prueba en: https://platform.openai.com/account/api-keys

4. Revisa logs en terminal
   └─ Busca líneas rojas o errores

5. Lee terreno troubleshooting en README.md
